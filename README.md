# Paginaris — SDXD Labs

Sitio informativo de Paginaris: privacidad, términos, soporte y solicitudes de datos personales.

## Páginas
- index.html — inicio
- privacy.html — aviso de privacidad
- terms.html — términos de uso
- support.html — soporte
- data-deletion.html — eliminación local y solicitudes ARCO
- licenses.html — índice informativo de servicios y licencias
- styles.css — estilos compartidos

## Publicación
Configurar GitHub Pages en Settings → Pages → Deploy from a branch → main → /(root). El sitio no se considera publicado hasta que GitHub Pages confirme el despliegue y proporcione su URL.

## Mantenimiento
El aviso se preparó a partir de una revisión estática de Paginaris 2.0.15.8-beta-monetizacion (versionCode 226). Antes de cada lanzamiento, revisar SDK, permisos, servicios externos, comportamiento de red y declaración Data safety de Google Play. Actualizar este sitio cuando cambie cualquier tratamiento.

La documentación es informativa y no constituye asesoría ni certificación de cumplimiento legal. Se recomienda revisión por profesional del derecho mexicano antes de distribución pública.
